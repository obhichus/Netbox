Data tečou jedním směrem. Žádný testovací provoz se do sítě neposílá.

Inventář nikdo neplnil ručně. Přišel ze snímku sítě a u každého objektu je vidět, ze kterého. Když se síť změní, import se spustí znovu a NetBox se dorovná. Kontrola je simulace nad modelem sítě, takže je bezpečná a dá se pustit i tam, kam bys testovací pakety neposlal.
