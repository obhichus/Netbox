# Prezentace pro vedení SŽ

`netbox-sz-vedeni.pptx`: „Evidence sítě jako doklad kybernetické bezpečnosti“, 18 slajdů s poznámkami řečníka
(15. 9. 2026). Obsah po slajdech je v `docs/PROJEKT.md` (7.3), plné znění textů a poznámek v `SLIDES.md`.

Soubor je znovu vygenerovaný z původního skriptu `gen.js` (pptxgenjs, obě pozdější úpravy zarovnání
zahrnuty). Velikost souhlasí s původně doručeným souborem (377 295 B); bajtově se liší jen časovými
razítky uvnitř souboru.

Úprava a nové vygenerování:

```bash
npm install pptxgenjs@3.12.0
node gen.js        # vytvoří netbox-sz-vedeni.pptx v aktuálním adresáři
```
